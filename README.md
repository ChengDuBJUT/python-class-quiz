# Python 编程基础与应用 · 题库练习站

**在线练习（不用下载）**：https://chengdubjut.github.io/python-class-quiz/

参照同学开源的 [mvstats-quiz](https://ledoo-bjut.github.io/mvstats-quiz) 做的静态题库站，纯 HTML/CSS/JS，无构建、无外链依赖、无后端。进度、收藏、错题只存在自己浏览器的 localStorage，不上传服务器。

## 打开方式

- **在线**：打开上面的 GitHub Pages 地址，手机 / 电脑浏览器都能用。
- **本地**：双击 `index.html` 即可。若浏览器对 `file://` 的本地存储有限制，可在目录内起个静态服务：

```bash
python3 -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765/index.html
```

## 部署与更新（GitHub Pages）

仓库 `ChengDuBJUT/python-class-quiz` 的 `main` 分支根目录就是 Pages 源；`.nojekyll` 让 GitHub 跳过 Jekyll、原样发布静态文件。改完题目或样式后：

```bash
git add -A && git commit -m "更新题库" && git push
```

约 1 分钟内自动重新构建，同学刷新页面就能看到新内容，不需要重新打包分发。

> 仓库是 public（GitHub Pages 免费版要公开访问必须如此）。`robots.txt` 已设置不被搜索引擎收录；若希望被搜索到，删掉它即可。

## 功能

- 章节（1–12）、题型、考试范围三重筛选，随机顺序
- 收藏、错题本（客观题答错自动收录，答对自动移出；主观题可自评收录）
- **「不会 · 看答案」**：练习页不用作答，直接显示正确答案 / 参考程序与解析，该题自动记入错题本；掌握后可点「已掌握（移出错题）」移出。看答案按未掌握计入已答、不计入答对，进度条会标注「含看答案 N」，交卷清单里标为「看答案」以免与真正答错混淆
- **「问 DeepSeek」**：把当前题按固定格式（章节 / 题型 / 题干 / 选项或代码 / 输出格式要求）打包，复制到剪贴板并在新标签打开 `chat.deepseek.com`，粘贴发送即可。官网不支持 URL 预填（`?q=` 只对装了自动发送油猴脚本的人生效），所以走「复制 + 跳转」，装了脚本的人点一下就是全自动
- 抽题组卷：章节多选 + 题型 + 范围 + 题量 N + 按题型比例抽样
- 交卷小结：正确率、答错 / 看答案 / 未答清单、「只练错题」
- 快捷键 `1`–`5` 选题、`Enter` 提交、`0` 不会看答案、`←`/`→` 翻题
- 进度、收藏、错题、知识点勾选全部存在浏览器 localStorage，不上传；只有你主动点「问 DeepSeek」时，当前题目才会被复制并带进你自己的 DeepSeek 会话

## 数据来源与已知缺口

1. 教材：`Python编程基础与应用习题及答案.docx`，共 14 章，按考试范围只取 **第 1–12 章**；第 13、14 章未入库。
2. **教材第 1、2、6、7、8、11、12 章的判断题答案整段空缺**，已按 Python 语义 / 教材口径补齐，题目解析里会显示提示，建议与任课教师核对。个别有口径分歧的题（如 ch8 判断 5「对象方法可以由类和对象调用」按教材判错）在解析中单独说明了。
3. 部分章节简答题答案为教材原文的「略」，站点显示「教材未给出参考答案」。
4. 少数编程题（如 ch6 第 8 题、ch12 第 7 题）教材未给参考程序，站点标注说明。
5. 教材第 2、13、14 章答案编号印刷错乱，解析脚本按「出现顺序」而非印刷编号与题号对齐；第 6 章选项里重复的字母标签已按位置规范化为 A/B/C/D。
6. 24 道代码自测题中 21 道用真实 Python 执行核验过输出；ch12 两道依赖 numpy/pandas、ch3 一道选项为文字描述，按库语义给定答案。

## 目录结构

```
python-class-quiz/
├── index.html          页面结构
├── styles.css          样式（沿用参考站的暖纸配色，浅色主题）
├── app.js              答题 / 判分 / 收藏 / 错题 / 组卷 / 进度
├── code_lab.js         代码复习模块
├── data/
│   ├── questions.js    window.QUESTION_BANK + window.CODE_LAB（线上实际加载，自动生成，勿手改）
│   └── questions.json  教材题中间产物，便于二次处理
├── tools/
│   ├── build_bank.py       解析教材习题 -> questions.json
│   ├── build_code_lab.py   汇总代码文件 + 代码自测题 -> questions.js
│   └── patch_app.py        （一次性）从参考站 app.js 生成本站 app.js
├── .nojekyll           跳过 Jekyll 构建
├── robots.txt          不收录进搜索引擎
└── README.md
```

`tools/source/quiz_lines.txt`（教材 docx 导出的逐行文本）、`tools/diagnostics.txt`、浏览器冒烟测试脚本含本地原始材料或本机路径，已由 `.gitignore` 排除，不在仓库里。

## 重建数据

站点本身开箱即用，**只有要重新解析原始资料时才需要**以下步骤；原始资料（`Python编程基础与应用习题及答案.docx`、`pythonProject-2025/chapter1..12`）不在本仓库，需要本地自备：

```bash
cd tools
python3 build_bank.py        # 依赖 tools/source/quiz_lines.txt（由 docx 导出）
python3 build_code_lab.py    # 依赖站点目录上一级的 pythonProject-2025/chapter1..12
```

`patch_app.py` 只在初始化时跑过一次，之后不要重复执行（它匹配的是原始参考站文本）。
